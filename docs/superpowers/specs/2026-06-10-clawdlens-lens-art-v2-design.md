# Lens Art v2 — Design

**Date:** 2026-06-10
**Status:** approved
**Goal:** Replace hand-crafted Lens block-art with build-time-generated braille icons from real Lucide SVGs (n8n's own icon set), upgrade node names to figlet miniwi big text, render the HUD `NOW` title in OpenTUI's tiny ASCII font, add an empty-state splash, and a breathing pulse on the think box during long thinking stretches.

## Research grounding (all verified by execution under Bun)

- **OpenTUI built-in ASCIIFont** (`@opentui/core` 0.3.2, already a dependency): 7 fonts — `tiny` (2 rows), `block`/`slick`/`grid`/`pallet` (6), `shade` (8), `huge` (11). Charset A-Z/0-9/punctuation, lowercase auto-uppercased. `renderFontToFrameBuffer(buffer, {text,x,y,color,font})` draws straight into the same `OptimizedBuffer` Lens's `renderAfter` receives; `measureText({text,font})` is pure. All glyphs single-cell-wide (verified across every glyph of every font). No image/sprite support exists in 0.3.2 — the blit primitive is `OptimizedBuffer.drawFrameBuffer`.
- **Braille icon pipeline** (prototyped at `/tmp/lens-art-lab`, 54/54 samples dimension-exact): Lucide SVG → `@resvg/resvg-js` (NAPI prebuilds; works first-try in Bun) at 768px using the **alpha channel** as ink coverage → area-average downsample at braille dot pitch (2×4 dots/cell, square dots) → threshold ~0.28-0.35 → U+2800-28FF strings. Lucide's 2px stroke is too thin at icon size: bump `stroke-width` to **3.0 (7×3) / 2.5 (13×5)** and set `stroke="#ffffff"`. Contain-fit + center. Gotcha: `RenderedImage.pixels` is a COPYING native getter — hoist `const px = img.pixels` outside loops (a per-pixel access OOM-killed Bun, exit 137).
- **figlet** (npm, MIT, 1.9M dl/wk, pure JS): `figlet.parseFont(name, fontData)` + `textSync` works under Bun with zero runtime fs via `figlet/importable-fonts/*`. **miniwi** = smallest lowercase font, 3 rows, half-block glyphs (`▗▜▘▛▌▙` U+2580-259F), e.g. `think` = 9 cols. Mini/Small are pure-ASCII alternatives.
- **Glyph safety:** braille U+2800-28FF is EAW-Neutral → always 1 cell (the safest set for the documented tmux ghosting gotcha; U+2800 is a true blank). miniwi/tiny block glyphs are the same class the app already ships.
- **Rejected:** image-to-ascii/ascii-art/asciify-image (dead native deps or 1px-per-cell illegible), terminal-image (requires bg paint — violates transparency), cfonts as dep (GPL + redundant), sextants U+1FB00 (font coverage too spotty), chafa (great quality but external binary; in-repo 30-line quantizer suffices).

## Decisions (user-confirmed)

1. **Icons: braille**, generated from Lucide SVGs at build time, two sizes (7×3 and 13×5).
2. **Node names: figlet miniwi** (3-row lowercase), pre-rendered at build time.
3. **Extras: empty-state splash + HUD `NOW` in tiny + thinking-state pulse** (breathing highlight on the think box during long thinks).
4. Land as its own PR off main (PR #16 merged first).

## Design

### Codegen (`scripts/gen-icon-art.ts`)

One build-time script, run manually (`bun run gen:art`), output **committed**; `@resvg/resvg-js` and `figlet` are devDependencies only — runtime and the published npm package stay dependency-free.

- **Inputs:** vendored Lucide SVG path data inline in the script (no network at codegen), keyed by `ArtKey`:
  | ArtKey | Lucide icon |
  |---|---|
  | prompt | zap |
  | thinking | lightbulb |
  | text (chat) | message-circle |
  | tool | wrench |
  | bash | terminal |
  | edit | pencil |
  | read | file-text |
  | search | search |
  | web | globe |
  | task | network |
  | skill | star |
  | todo | list-checks |
  | result | check |
- **Outputs** → `src/ui/panels/lens/iconArt.gen.ts` (header comment: "GENERATED by scripts/gen-icon-art.ts — do not edit"):
  - `ICON_ART_7: Record<ArtKey, string[]>` — 3 rows × 7 cols braille.
  - `ICON_ART_13: Record<ArtKey, string[]>` — 5 rows × 13 cols braille.
  - `LABEL_ART: Record<"prompt"|"think"|"tool"|"result"|"chat", string[]>` — miniwi 3-row lowercase, trailing-space-padded to equal width per label.
- Per-icon stroke/threshold overrides live in a small table in the script (globe-style fixes).
- The old hand-crafted `ICON_ART` in `iconArt.ts` is deleted; `iconArt.ts` re-exports from the generated file (keeps import paths stable) and keeps `ART_W/ART_H` semantics per size.
- **Tests** (`tests/icon-art.test.ts`, rewritten): all 13 keys present in both sizes; exact dims (7×3, 13×5); icon glyphs ∈ U+2800-28FF ∪ space; label art rows = 3, glyphs ∈ U+2580-259F ∪ box-drawing ∪ space; all five labels present.

### Lens rendering changes (`src/ui/panels/Lens.tsx` + geometry)

- **Wide-box tier:** width ladder gains a top step — `BOX_W_WIDE = 17` boxes with 13×5 art when `width >= rowNeed(5, 17, GAP_LABEL)` (= 2+85+36+2 = 125); below that, current 13-col boxes with 7×3 art; the rest of the ladder unchanged. `nodeLayout` returns the art size with the mode.
- **miniwi names:** the 1-row name under each box becomes the 3-row `LABEL_ART` (centered, fg as today: active bright / dim otherwise), detail row beneath (plain, dim). `NAME_ROWS` 2 → effectively 4 (`LABEL_ROWS = 3` + 1 detail). Height ladder order: wide-art → art → **miniwi→plain names** (drop 2 rows) → glyph boxes → economy → heartbeat → timeline → ribbon → sub-row.
- **HUD `NOW` in tiny:** inside the HUD band, render `NOW` via `renderFontToFrameBuffer(buffer, {text:"NOW", font:"tiny", color:accent})` occupying band rows 1-2 left; the now-line renders to its right of it; status line on row 3. Plain-text fallback when the band ever shrinks (it doesn't today — keep the guard trivial: if measureText width doesn't fit, draw the old plain title).
- **Empty-state splash:** when `presented.length === 0` (no beats revealed), skip the pipeline entirely and draw `CLAWDLENS` centered in `slick` (6 rows, coral+dim two-tone) with a dim hint line below ("waiting for session activity · : sessions"); `tiny` font when slick doesn't fit the width; HUD band still drawn.
- **Thinking pulse:** `thinkPulse = (status === "working" || status === "running") && head beat kind === "thinking"`. The Lens `<box live>` becomes `live={animate || thinkPulse}`. In `renderAfter`, when `thinkPulse && !animating`: think box border + icon color = `lerpHex(laneHex, theme.pulseHot, breathe(now))` (1.8s default period). While `animating`, the orbiting ring already covers it (no double effect).

### What does not change

Player/cursor, reducer/parse, wires/trail/ring/sub-row mechanics, other panels, transparency rule, keys.

### Testing

- Codegen output: committed file + the rewritten icon-art tests (dims/glyph ranges/coverage); a `bun run gen:art && git diff --exit-code` CI step is NOT added (manual regen; YAGNI).
- Geometry: wide-tier ladder tests (thresholds, art size selection).
- Visual: tmux at 150×36 (wide tier + miniwi + splash on an empty session), 120×30, 100×30, 80×24; `-e` frame-diff for the thinking pulse (drive a thinking-heavy session or replay).

### Out of scope

Sub-row circle glyphs (stay single nerd/unicode glyphs), Flow/Git panels, animated icon art, chafa pipeline, sextant variants.
